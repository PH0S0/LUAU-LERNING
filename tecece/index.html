História da LUA (LUAU)

Lua é uma linguagem de programação criada no Brasil que se deu início pela necessidade de criar uma linguagem de programação simples, adaptativa e leve. Sendo uma ferramenta capaz de ser usada por pessoas que não são programadores independente da complexidade do projeto, tendo uma linguagem que pode ser interpretada e tendo uma sintaxe (forma de organizar os comandos) bem simples.
